# 地图实现说明：原理与你需要做的事

本文档说明「校内彩色、校外灰色」在前端如何实现，以及上线前你侧需要准备的数据与合规事项。

---

## 1. 需求在代码里怎么实现

1. **底图**  
   当前演示使用 **OpenStreetMap 栅格瓦片**（无需密钥，仅适合开发与低流量演示）。文件：`frontend/src/components/CampusMap.tsx`。

2. **校外变灰**  
   在世界范围画一个**巨大矩形**，再在中间按 **GeoJSON Polygon 的「洞」（内环）** 抠掉校区范围。  
   只对「矩形减洞」后的区域做**半透明深色填充**，视觉上就是：校区内仍是彩色底图，校外被一层灰蒙住。  
   校区边界线用**金色描边**（`campus-edge` 图层）便于辨认。

3. **多校区**  
   在 `frontend/src/data/campuses.ts` 里为每个校区配置：`center`、`zoom`、校区闭合多边形 `ring`。地图初始化与遮罩、描边都会读这里的定义。

4. **冒泡卡片**  
   事件/帖子数据里带 `lng`、`lat`，用 MapLibre 的 `Marker` 挂自定义 DOM（缩略图 + 文案），点击后在弹层里展示全文。

---

## 2. 你需要做什么（清单）

| 事项 | 说明 |
|------|------|
| **真实校区边界** | 用学校官方 GIS、QGIS、或 [geojson.io](https://geojson.io) 绘制/导出 **Polygon**，替换 `campuses.ts` 里对应校区的 `ring`（首尾坐标闭合）。若遮罩反了（整屏被灰盖住），把 `ring` 顶点顺序**整体反转**再试。 |
| **坐标与地址** | 每条校园事件、每条帖子需要可靠 **经纬度**；仅有文字地址时，需批量地理编码或维护「校内 POI → 坐标」表。 |
| **底图与合规** | OSM 免费但有使用政策与稳定性限制；正式环境建议：**Mapbox / 高德 / 腾讯等商用方案**或自托管瓦片，并处理审图、版权与隐私协议。 |
| **可选：Mapbox 等密钥** | 若改用需 Token 的样式，可把样式 URL 放到环境变量（如 `VITE_MAP_STYLE_URL`），在 `CampusMap.tsx` 中读取，**不要把密钥提交到公开仓库**。 |

## 5. 彩色平面图模式（默认）与标注流程

默认使用 **平面图 + 比例坐标**（`nx` / `ny` 为 0~1，相对底图左上角），不再依赖街图瓦片。环境变量见 `frontend/.env.example`（`VITE_BASEMAP_MODE=image` / `VITE_BASEMAP_IMAGE`）。

### 你要做的

1. **放入底图**  
   将校园彩色平面图放到 `frontend/public/`，文件名与配置一致，例如：`campus-basemap.png`（**带透明通道的 PNG**）或 SVG。校园以外为透明像素时，会**直接透出**下层页面底色（`body` 背景），地图容器不再垫实色。技术上仍是**一张矩形画布**，坐标相对外接框。  
   若文件不存在，会自动使用 `campus-placeholder.svg` 提示路径。

   **坐标说明**：标注用的 `nx` / `ny`（0~1）始终相对**整张图的外接矩形**（包含四周透明留白）。若你希望比例尺更「贴校园」，可在导出矢量图时把 **viewBox / 画布裁紧**到校园外围，减少透明边。

2. **在网页里标注楼名、路名等**  
   打开站点后点击顶部 **「标注数据」**：滚轮缩放、空白处拖动平移，在图上 **单击** 加点，在侧栏改名称、类型、备注。  
   数据会 **自动写入本机浏览器 localStorage**，下次同一浏览器打开仍在。

3. **备份与团队共享**  
   - 本地执行 **`npm run dev`** 时，标注页可点 **「保存到 public」**，会直接写入 **`frontend/public/annotations.json`**（由 Vite 开发服务器接收请求写盘；纯浏览器无法绕过此机制写项目目录）。保存成功后会同步更新 **localStorage**，同一浏览器下次打开仍有数据。  
   - 若 **`public/annotations.json` 已存在**（例如已提交到仓库），而本机还**从未**在站点里存过标注缓存，打开应用时会**自动**把该文件读入 localStorage，换电脑、换浏览器也能看到与仓库一致的标注。  
   - **`vite preview` / 正式线上** 没有该接口，请用 **「导出 JSON」** 再手动放进 `public/`。  
   - 也可把导出的文件复制到 `frontend/public/annotations.json`，他人用 **「从 public 加载」** 同步（会覆盖当前本地标注，需确认）。  
   - 上线构建后，`public/` 内文件会随站点一起发布。

4. **事件 / 帖子在平面图上的展示与交互系统**  
   - **交互方式更新**：底图空白区域已禁用直接点击。必须点击经 **「标注数据」** 确定的 **「标注框」**（Annotation Regions）来发起新帖子。系统会自动携带地点的 ID 和名称。  
   - **分层位移定位**：所有与地点相关的程序都使用标注框的位置系统。  
     - **记忆中心点**：记忆流定位指向标注框的 **中心点**（nx + nw/2, ny + nh/2）。  
     - **气泡挂载点**：地图上的气泡尖端对齐在标注框的 **上边缘**（ny）。这样气泡内容自动悬浮在地名 Label 之上，不再阻挡视觉。  
   - **数据回退**：仅当无法匹配到标注框时，才回退到记录本身的原始 `nx`、`ny` 散点坐标显示。

- 模式开关与底图路径：`frontend/src/config/basemap.ts`
