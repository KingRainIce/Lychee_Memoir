# 深大初雪皮肤限时掉落！💙💌🌌🧊❄️⛄️

💭💭💭   
  
 今天冬至   
 夜最长   
 梦也该最长   
  
 你说深圳不下雪   
 但我想，万一呢   
  
 我听到TA说   
 “深大，我来赴约了~”   
  
 ❄️❄️❄️   
  
 睁开眼   
 星空广场的彩色柱尖   
 汇集着层层雪花   
 迎客松前的地面   
 已覆上厚厚的“告白”   
 橘红色的座椅   
 搂住漫天的“人间访客”   
  
 💌💌💌   
  
 仰头看   
 碎光从枝叶间隙簌簌落下   
 洗星湾的冰面映射斑驳的树影   
 雪落无声的静谧里   
 “君子进德修业”巍然伫立   
 白雪描摹着致理楼每一道光影   
 仿佛时光在此刻也被染上霜迹   
  
 💙💙💙   
  
 冬至“雪落深大”   
 染一层银色的梦   
 愿所有等待都不被辜负   
 所有奔赴都有温度   
 所有遥远都会抵达   
 所有思念都被听见   
 冬至安康，团圆，快乐，顺遂   
 愿你的长夜有暖灯   
 远方有回响
