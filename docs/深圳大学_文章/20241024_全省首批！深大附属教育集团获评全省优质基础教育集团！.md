一、总体定位

指导思想

近年来，党和国家先后出台了关于教育发展的若干历史性文件和重要指导意见，《中共中央国务院关于支持深圳建设中国特色社会主义先行示范区的意见》的发布，为深圳教育带来了千载难逢的历史机遇。集团发扬敢为天下先的精神，融入世界格局，赋能中国新教育，创新“深派”教育，开展辐射粤港澳大湾区的教育新文化运动。牢牢把握“先行先试”的使命担当，创造更多可复制可推广的经验，对标国际一流教育，助力中国特色社会主义先行示范区的发展。

发展原则

坚持党的领导，落实党的教育方针，办好植根中国大地、具有深厚中华文化根基、中国特色的集团化教育。围绕全国教育大会提出的“凝聚人心、完善人格、开发人力、培育人才、造福人民”的工作目标，以教师为本，为人民服务，建设高品质的教师队伍，争当“四有好老师”和“四个引路人”。以学生为中心，面向人人，“德智体美劳”五育并举，培养适应未来的核心能力和创新精神，努力让每一个学生都打好迎接幸福人生的基础，培养可持续发展的未来学子。促进优质教育均衡布局，建设创新、开放、融和、共享的教育生态格局，打造精致教育，培育精品学校（园）。

一、坚持党对学校教育工作的全面领导

落实党组织领导的校长负责制。 集团各成员学校建立党组织领导的校长负责制，细化并实施党组织会议和校长办公会议议事规则，制定发展规划，研究重大事项，确保学校正确办学方向。

深化集团成员学校党建工作。 集团的党建架构以学校所在的区教育工委或深大党委引领，下设各成员校党支（总）部的二级分支状。深大附中党委和深大附属实验中学党总支在深圳大学党委的领导下，其他成员校党支部均隶属于各区教育工委。紧密结合学校实际，围绕“发展教育抓党建，抓好党建促教育”的原则，从组织、制度、作风等方面着手，强力促进学校管理效能的提升，进一步激活党组织的生命力，构建学习型的基层党组织。不断加强党员教师队伍建设，助力打造优质的师资队伍，提升教学质效。

六、打造教育共同体，促进内涵发展

凝炼“和合”文化。 秉持“让每一个孩子全面而有个性地发展”理念，建设集团“和合”文化，合作、和谐，倡导文化立校、文化创新。集团一盘棋，调动全方位资源和各成员校的积极性，形成集中力量办大事的显著优势；建设“同而不同、不同而同”的教育发展共同体；让恪守“知行合一”、筑梦“天人合一”精神成为集团成员共同的价值追求和精神取向，成为师生的内心情怀与行为自觉。

![图片](https://mmbiz.qpic.cn/mmbiz_png/7pKMK6ibd9naW9Rlu0qqA08HUicicqbCYSniajqDokHUCtWBayxYQd9BJCoXQL6bb8GYMgBfpIz28p39W8QCFkRU9g/640?wx_fmt=png#imgIndex=36)

统一集团文化标识。 集团秉承深大“脚踏实地，自强不息”精神和“自立自律自强”校训，不断凝炼“和合”文化，携手构建教育发展共同体。集团鼓励各成员学校坚持自己的办学精神、办学理念、办学特色。集团文化标识为深大首位字母“S”形状，兼有大学（University）的涵义，由“似书页又似树叶形状”的三个部分构成，由上至下颜色为荔枝红、建筑灰、教育蓝，象征“学校·人·未来”的概念组合，也象征“土壤、生命、阳光”的寓意。教育蓝可以结合各学段变色，如绿（幼儿园）、黄（小学）、浅蓝（中学），寓意着幼儿园、小学、初中、高中以及大学各成员校的高度融合。

打造教育协作共同体。 依托从幼儿园到大学完整的学生发展体系，集团充分挖掘校内外资源，统整融合学校、家庭和社会的教育价值，为学校教育赋能。集团各成员学校（幼儿园）规划了家庭教育整体工作体系，包括筹建学校家长委员会工作坊、成立心桥家长学校、挂牌设立家委会工作室、启动“幸福家长培训课程”工程等家校共育模式。

- 深大在附中设立科技创新教育基地，指导附中学子参加各类科技创新大赛。
- 附中游泳队在深圳大学粤海校区训练，高标准的场地，优秀的深大教师团队，全方位服务附中的孩子。
- 深大实验小学借助深圳大学丽湖校区，充分利用大学各方面资源，对学生进行训练，
- 深大后海小学的游泳校本课程借助了毗邻学校的海月社区的游泳池，充分挖掘大学与社区的资源，全方面培养集团的学生。
- 深大幼儿园地处深大校内，从小置身高等学府中，与大学教授零距离接触，让科学精神、创新意识、实践能力在孩子们心中慢慢生根发芽。
