# 🌳比较有“树张力”的一集

人随春好，春与人宜🍃   
 泥土翻个身   
 把一季的生机抖了出来   
 天空变高，云变软   
 白天的时间慢慢变长   
 绿色的春天醒过来了   
 万事万物都在变好   
 我们也应当如此——   
 像一棵树一样   
 在这个充满希望的季节扎根   
 向着光亮的地方奋力生长   
  
 💚👒🌱🍀🌳📚📗🪴🌿   
 送给你   
 “树张力”满满的SZU   
 不过   
 别总盯着屏幕里的春天啦~   
 出门“充充电”   
 和真正的春天握个手~   
 在树荫下散散步   
 听听叶子与花的对白   
 到湖边坐一坐   
 看水波把阳光揉碎又铺平   
 让心情像树枝一样舒展   
 让呼吸像春风一样轻盈   
  
 今天起，“种”下一抹绿   
 收获一整年的温柔与希望~   
 迎接春天，迎接快乐！
