（2023-2024年度深圳大学“十大文化精品项目”）

优秀的传统文化

是我们中华民族珍贵的精神财富

更是社会主义核心价值观的深厚源泉

其中，中国书法与国画

是中华优秀传统文化宝库中的璀璨明珠

承载着千年的艺术魅力

深入而全面地理解书法与国画

不仅是对中华优秀传统文化的

尊重与传承

更是对这一文化精髓的创新与发展

它们所蕴含的深厚底蕴与高尚精神

无疑为我们在新时代背景下

坚守文化自信、推动文化繁荣

提供了坚实的理论支撑与实践指导

2023年12月，人文学院申报的 “深圳大学师生校友书画精品展” 获批“深圳大学十大文化精品项目”。项目致力于形成具有推广价值的文化育人工作经验，进一步促进文化传播工作交流，做好中国优秀传统文化的传承和弘扬工作，同时凝聚师生校友力量，更好地弘扬深大精神，打造深圳大学校园文化品牌。

投稿要求

1.作品类别：书法、国画

2.作品内容：体现中华优秀文化、爱国情怀。书法内容提倡原创诗文，或是积极向上的历代诗文、诗词、楹联、文赋等，书写古代诗文应注意使用权威版本，内容须相对连贯、完整。当代内容应以正式出版或主流媒体公开发表为准，内容主题须相对完整，改编、网络文本不在征稿范围内。

3.作品要求：硬笔书法可使用中性笔、钢笔、秀丽笔等。所有作品用纸规格统一为四尺对开（138cm×34.5cm），一律为竖式。手卷、册页等形式不在征稿范围之内。已入展过其他展览的作品请做好备注。 每人投稿作品不超过两件，须一次性邮寄。

4. 其他说明：所有作品请勿装裱（特殊形式可用浆糊简单托裱），机器胶膜托裱作品不予评审。请随稿附送 《深圳大学师生校友书画精品展登记表》（后文扫码下载） ，便于工作人员登记。投稿信封必须注明“深圳大学师生校友书画精品展”字样。本次活动不收取参评费，所有作品归主办方收藏。

5.截止时间： 2024年9月20日 （以作者当地邮戳为准）。

6.收稿地址：广东省深圳市南山区深圳大学粤海校区国学院书画室（H5-009），联系人：深圳大学国学院书画工作室，联系方式：15220241861。

入展说明

1.由主办方邀请专家组成评审委员会进行评选。

2.视收稿质量和具体情况，拟评选入展与入选作品100件，编入正式书号出版的《深圳大学师生校友书画精品展作品集》。

3.由主办方向参展作者颁发荣誉证书及作品集。

4.优秀作品作为深圳大学校园常设展品入藏。

5.主办方为所有入展作品提供宣传推广平台。

6.应征稿件如涉及版权等纠纷，投稿人自负其责，与主办方无关。

7.凡应征投稿即视为已同意并遵守本征稿启事的各项规定，在法律许可范围内主办方拥有本启事最终解释权。
