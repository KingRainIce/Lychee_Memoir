# 今日，宜嘘寒问暖

当金风飘菊蕊   
 当玉露泫萸枝   
 九九重阳   
 也就如约而至   
  
 气候舒适，日子温馨   
 我们可以一起   
 簪菊花、佩茱萸   
 登高山、眺远方   
 尝花糕、放纸鹞   
  
 最重要的是   
 别忘了拿起手机   
 给家里的长辈打一通电话   
 真诚地祝愿他们   
 健康长寿，幸福安康
