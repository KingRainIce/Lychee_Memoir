# 迷彩映荔园，青春正飞扬

💪💪💪🫡🫡🫡   
 以挺拔军姿，写就青春序章！   
  
 当阳光遇见迷彩   
 倾洒在荔园训练场   
 2025级新生   
 正用炽热汗水   
 淬炼成长的锋芒   
 谱写属于他们的热血乐章   
  
 以脚步丈量坚韧   
 以呐喊回应理想   
 从青涩到坚毅   
 这段汗水与欢笑交织的时光   
 将成为大学生活中最难忘的开场！   
 加油！新深大人！
