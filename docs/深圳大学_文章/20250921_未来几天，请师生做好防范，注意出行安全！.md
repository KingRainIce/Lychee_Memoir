“桦加沙”庞大的云系

台风“桦加沙”今天（21日）早晨5点钟其中心位于距离菲律宾马尼拉东偏北方向约770公里的西北太平洋洋面上，就是北纬17.9度、东经127.3度，中心附近最大风力有15级（50米/秒），中心最低气压为940百帕，七级风圈半径300-350公里，十级风圈半径150-180公里，十二级风圈半径80-120公里。

台风来袭，如何避险

![图片](https://mmbiz.qpic.cn/mmbiz_gif/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan28461VKr9NYkKialyp3jQVG8cxYJFqQjJOFibehBMqyKqe8ca5Y9gRyvv5g/640?wx_fmt=gif#imgIndex=12)

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJu5IGNAf9WOyK7QKzQjiax2icyuKcFeib1srCVhGkHVicus1WWD8Y4dHNYmTWods3ib7Dwy9XEWyUK8dQ/640?wx_fmt=jpeg#imgIndex=13)

在室内

1. 尽量避免外出， 检查电路、煤气 等设施的安全，固定或收回屋外、阳台上的一切可移动物品，如花盆等。

2. 关紧门窗，在窗户上用 宽胶布贴成“米”字 ，加固玻璃，以防被风吹破伤人。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan284fj0nrs8lFRGE1ZI6icKC55mMtPfoWhl7xV1ib9Nft6niaZ89IGxalTdnw/640?wx_fmt=gif#imgIndex=14)

3. 当台风中心经过时，风力会减小或者静止一段时间，但当 台风眼过境后，强风将会突然吹袭 ，不要外出，应当继续留在安全处避险。

4. 台风往往 伴随暴雨 ，注意防范强降水可能引发的 山洪、泥石流 等地质灾害。居住在危旧住房、低洼地区的居民，应 及时转移 到安全地带。

![图片](https://mmbiz.qpic.cn/mmbiz_png/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan2849ecQibC8gibVibJNCwy7sOAnMqcpqN6KwBIvnfeppvftWwwHyeG0oNBpQ/640?wx_fmt=png#imgIndex=15)

5. 沿海居民还应 关注风暴潮预警 ，需要转移时及时撤离。

在户外

1. 台风来袭时，如果身处户外，应尽快去 结实的建筑物内避险 。

2. 行走时应尽量抓住固定物体， 慢慢靠边行走，弯腰降低重心 。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan284ovicQejqHa4QzVw2h7QYmVBXMAm9fkxeFvoOibXUeI2NnOFAnkL1cfuw/640?wx_fmt=gif#imgIndex=16)

3. 不要在 临 时搭建物、广告牌、铁塔、大树 等附近避风避雨，小心脚手架、电线杆、空调室外机等，这些物体可能倒塌掉落。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan284lbTia7E7tVXFocly47GLEYCD3vWntqP9X7JCgYMib7jr7pRNQUkRTTHw/640?wx_fmt=gif#imgIndex=17)

4. 驾驶车辆时遇到狂风要 减速慢行 ，狂风中路边的树枝、搭建物都可能是危险来源。经过积水路段时，如积水超过轮胎的一半，就不要贸然涉水，以防车辆被淹。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/QIicUeHELQ9SOfiayuicdM3lAF7hiaxan2842bEeddS0J5jjzSoRsiakW8LibwBgmx3vibAic5WWnXocKXTb57rVjmsLTg/640?wx_fmt=gif#imgIndex=18)
