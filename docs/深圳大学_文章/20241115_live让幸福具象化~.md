# live 让幸福具象化~

今天“实况”一下   
 我们SZUer的校园生活~   
 是live也是life   
 live图的生命力和流动感   
 让定格的瞬间活灵活现   
 让幸福有迹可循   
  
 用涂鸦live图的方式打开深大   
 像翻阅一组会动的日记   
 一帧帧瞬间，一点点小美满   
 都能让我们感受到鲜活的幸福   
  
 每日一问“今天吃什么？”   
 刚排队正好碰上小巴到站   
 从图书馆出来看见绝美的晚霞落日   
 还有再平常不过的萌宠和美食   
 再熟悉不过的校园风景……   
 我们的大学生活   
 有忙碌的奔波   
 也有琐碎的日常   
 在一次次日升月落里   
 我们相信所有的美好都在路上   
  
 期待你分享   
 在学校的幸福瞬间~
