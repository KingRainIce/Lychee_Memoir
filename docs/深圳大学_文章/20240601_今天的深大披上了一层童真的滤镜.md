# 今天的深大 披上了一层童真的滤镜

我们都曾带着好奇心与想象力   
 做天马行空的梦   
  
 今天的深大   
 披上了一层童真的滤镜   
 当数字魔法遇上古老的黏土艺术   
 一场别开生面的校园童话正在上演   
  
 我们穿越时空隧道与她相遇   
 看科技与艺术碰撞出火花   
 看SZUer释放热烈与酣畅   
 看萌宠为生活增色，变枯燥为生趣   
 看繁花似锦，绘出夏日画卷   
  
 这里有纯粹的快乐   
 这里有青春的涌动   
 这里装得下奇思妙想   
 这里守住了童真浪漫   
  
 原来生活可以这么像童话   
 愿我们一觉醒来   
 岁月依然静好   
 生活依然可爱   
 不论几岁，开心万岁！   
 祝愿所有小朋友大朋友   
 节日快乐！
