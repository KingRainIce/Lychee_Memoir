作为新质生产力代表之一，数字孪生技术正在医疗健康领域不断解锁新的应用场景。深圳大学附属华南医院聚焦新质生产力，以数字孪生技术为切入点，构筑医院“数智时空底座”，以患者为中心，在一体化便捷就医、精细化管理、个性化精准医疗等方面持续发力，实现医疗向“新”、服务向“心”。

什么是数字孪生

所谓数字孪生，就是围绕“虚实共生”的理念，将物理实体镜像映射到虚拟空间，生成“数字双胞胎”。就像照镜子一样， 通过“数字孪生技术”这面镜子，在数字世界生成医院3D可视化建筑模型，提供“万能视角”，实现整个院区的“可视、可管、可控”，以数字驱动关键环节，让资源配置得到最优解。

“患”位思考，让就医不再是难事

“我这病到底该挂哪个科？”

这是很多人在去医院前都会发愁的一个问题。为了解决这个问题，同时也为了让患者就医更高效、更便捷，华南医院在医院微信公众号上线了“AI智能导诊”功能,通过人工智能手段，面向居民提供24小时在线咨询服务，包括AI智能分诊、问病、问药、查询疫苗信息、辟谣较真等，还能实现一键快速预约。

同时，华南医院还推出了“智能陪诊助手”，为患者提供更为贴心的服务。这个“助手”会在个人页面中为每位患者生成一个就医日程，清晰展示预约日期，记录就医时间轨迹，便于患者快速复诊。此外，智能陪诊助手还能智能推荐下一步就诊环节，并在就医过程中主动推送消息指引，为患者提供虚拟陪诊、现实感知的全新就医体验。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJibO8akF4fCJfsIKU8tYvclWb8Yh8A9CR00q3q8qzZkHv96iadvXFb82G4LFicXdSY0KM4H7dJSA8aQ/640?wx_fmt=jpeg#imgIndex=2)

“真的很方便！在手机上就能快速找到想要的信息，像门诊排队情况、检查报告、住院每日费用清单、电子发票等等……”刘女士今年几次陪家人到华南医院看病住院，对使用过的这些线上功能赞不绝口，“特别方便，门诊不用排队就可以直接扫码缴费，住院押金在家就能缴纳，就连病案复印都可在手机上申请、快递到家，不用来回跑，以前跑医院让我头大，现在让我省了不少心呀！”

科技赋能，为医疗服务加把力

“妈妈，快来看看，这是机器人！”

看见正在工作的消毒机器人，一名小男孩兴奋地唤来自己的妈妈，并且好奇地打量着它。为了让精湛的医疗技术与5G、人工智能等技术更好地结合起来，方便患者就医看病，深圳大学附属华南医院围绕人工智能与机器人等特色领域，先后与兄弟医院和本土知名创新企业联合打造了多个高水平产学研转化平台，不断探索和尝试各类智慧医疗应用场景及模式——机器人消毒、机器人查房、机器人送药，甚至在机器人协助下完成远程探视……在深圳大学附属华南医院，这些都是天天在真实上演的医疗场景。

科技创新是发展医疗服务新质生产力的核心驱动力，数字化医疗、远程医疗、精准医学等新兴技术正在改变着传统的医疗模式。从打造机器人试点医院，到探索全国首创无人机智慧应急救援新模式，从成立国产手术机器人临床科研验证中心，到率先在国内成功开展国产机器人甲状腺癌根治临床研究手术，从成立国内首家医学数字孪生人实验室，到构建数字孪生医院……一直以来，深圳大学附属华南医院积极推动科技在医疗领域的应用，不断探索创新的医疗技术和服务模式。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJibO8akF4fCJfsIKU8tYvcl1yzeJJl79ZCc9vzoDxWDygZAPO5yn2XLqLvKhw0icZk76ejgF2F6JEg/640?wx_fmt=jpeg#imgIndex=3)

“聚焦新质生产力，我们必须让创新驱动的轮子加速‘转’起来！”华南医院院长吴松表示，数字孪生医院是智慧医疗的重要方向，深圳大学华南医院正利用数字孪生医院技术不断创新，搭建多元化的应用场景，触达医疗服务、科研创新、后勤管理、安全生产等各个方面，进行全生命周期健康管理，致力让居民享受最好的健康服务。

精益求精，用质量“说话”

“我们可以通过数字孪生医院管理后台系统，远程查看设备参数信息，就如同查看实体设备一样。”华南医院信息部助理主任杨凯介绍，除了联动各类物联设备数据后台，系统还可对医院的水电气、冷热源等能耗进行数据实时采集和分区计量，设置报警阈值，实现一屏智能管控，助力达成绿色、节能管理目标。

与此同时，华南医院致力于警医联动医院版“枫桥经验”建设，通过智慧化不断升级安全防卫体系，实现科技赋能，精准预警。安保人员可通过全院高清视频监控大屏实时监测医院动态，配合数字孪生平台，针对突发性事件及时调配现有人员，快速解决突发情况。通过物联感知、数据采集、隐患动态监控，结合安防消防设施运行状态和设备巡检状态，可以迅速捕捉医院内的蛛丝马迹，实现智能化风险分析预警。

“新质生产力”,创新驱动是“新”的关键，高质量发展是“质”的锚点。优化医疗资源配置，加强医院管理和运营效率，提高医疗服务的可及性和质量是实现新质生产力的基础。

以质量为驱动，华南医院运用数字孪生技术，将空间管理、设备管理、能源管理、安全管理、业务管理、临床服务等功能集于一体，通过拓展智慧门诊、智慧住院、数字化手术室、云诊疗、智慧物流配送、智慧后勤应用等，实现对患者、医生、设备、资源等的精准分析和优化，达到业务数据与空间环境的相结合，为医院运营管理插上了“降本增效”的数字翅膀。

![图片](https://mmbiz.qpic.cn/mmbiz_png/OaWJibLCM5zJibO8akF4fCJfsIKU8tYvcl41D6XNZ21V4MDNJP2fKUME7DSlp4AEHCVTYNDLeIEiaOrEbUynZCo7w/640?wx_fmt=png#imgIndex=4)

以“数智时空底座”的全局感知为基础，下一步，华南医院将进一步实现医院各大区域的信息融合和业务贯通，加强精细化的协同与运营，降低运营成本，提高医院管理与服务效率，让百姓过上健康的“好日子”。

个性化精准医疗，减少就医麻烦

看病还得带上一大沓病历和报告？医生问起病史时，挠破头也说不全？在数字孪生医院，以上情景都将不复存在。主诊医生进入数字孪生平台，即可一键调用患者以往医疗记录和问诊信息，根据系统中生成的数字孪生患者模型，医生可以综合评估患者病史与症状，高效作出医学诊断，尽快为患者作下一步治疗。

![图片](https://mmbiz.qpic.cn/mmbiz_png/OaWJibLCM5zJibO8akF4fCJfsIKU8tYvclrtVycicVyqwSYxav5VfVFaHaUr2qibMicHBCmtOWR65QVAcL0iaPezqbug/640?wx_fmt=png#imgIndex=5)

患者出院后，个性化健康监测将如影随形。患者管理小程序会提供随访通知、日常饮水记录、输尿管支架移除时间提示、复发率预测等服务，同时通过获得患者的生活习惯，帮助构建个人全生命周期的数字预测模型，提供全生命周期的预测记录分析和决策支撑。以上未来的种种，都离不开数字孪生技术。

“发展新质生产力，我们将进入精准治疗新时代。数字孪生技术的发展将为医学领域提供一条有价值的前进道路。”华南医院一直关注数字孪生技术在医疗保健领域的应用。吴松教授带领的科研团队发表《关于数字孪生技术在医学领域的机遇与挑战》一文，对数字孪生技术在医疗保健领域的应用进行了论述，并指出，该技术为疾病诊断和治疗、临床医学研究和个性化健康监测等方面提供了机遇。

服务不再“冷冰冰”，让就医更温情

在新质生产力视角下，抢抓数字孪生机遇，深圳大学附属华南医院坚持创新与质量双轮驱动，多元融合推动医院高质量发展，究其根本，始终离不开“以患者为中心”的核心理念。

“我们要有向‘新’的医疗发展，更要注重向‘心’的温情服务。”吴松院长表示，创新科技的应用并不是让医院变得像机器人一样“冷冰冰”，而是能够释放更多的人力、物力，有效整合资源，为患者提供更多的人文关怀，让他们感受到温情与暖意。

从成立全国首个公立医院爱心车队到举办公益音乐会，从建设“书香医院”到打造多功能特色中医药文化及科普基地，华南医院一直坚持人文为本，公益先行。

未来，华南医院将基于数字孪生医院的建设探索，不断优化医疗资源配置，让流程更科学、管理更高效、模式更连续、服务更温情，瞄准世界一流创新型大学附属医院，以更强的信心、更大的干劲向“新”求“质”、以“质”催“新”，围绕多层次、多样化的医疗健康服务需求，打通医疗服务“堵点”“痛点”，加快全面提升百姓就医的获得感、幸福感和安全感。
