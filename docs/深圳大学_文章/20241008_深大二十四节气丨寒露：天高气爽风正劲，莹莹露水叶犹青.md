*草木萧疏梧落黄*

*天高昼暖夜来凉*

寒露，是二十四节气之第十七个节气，秋季的第五个节气，也是节气里第一个带“寒”字的节气。《月令七十二候集解》中提到： “九月节。露气寒冷，将凝结也。” 寒露气温较白露时更低，露水更多。晨曦傍晚，原先草木上将凝未凝的莹莹露珠开始凝结成霜，从初秋微凉转为深秋寒凉。此时，白天秋高气爽，昼夜略带寒意。

![图片](https://mmbiz.qpic.cn/mmbiz_png/OaWJibLCM5zK0YJuyvMpuBlhEwjz8JrsNtEa1Chq3kUec2xgp7xPSGdiaGMrTSZgJzebbVhZgqYQHOyXRBztxW7g/640?wx_fmt=png#imgIndex=2)

“袅袅凉风动，凄凄寒露零。兰衰花始白，荷破叶犹青。” 来到晚秋由凉转寒的风口，人间寒秋也别有好风光。风把半个星球吹出“美拉德反应”，枫叶热烈似火温暖了寂寥，银杏叶金黄蓬勃装点了枯败，秋菊五彩斑斓地肆意盛开，落叶飘零回归大地的怀抱，给大地盖上“秋衣”。面对不同的风景也有不同的心境，不妨像秋日暖阳般明媚飒爽，迎接秋天的每一分颜色。

赏红叶

红叶多指枫叶，“霜叶红于二月花”说的就是寒露时的枫叶，旺盛且磅礴。恰巧天气还没有太冷，自古人们就有秋游的习惯，北方地区的人们多选择去郊外赏枫叶，身临其境地感受秋天的“热烈”。

赏菊花

农历九月又称菊月，寒露时“菊始黄华”，菊花此时普遍开放，和大多数春夏盛开的花不同，菊花是反季节的花，越是霜寒露重，越是开得艳丽。古人多崇尚菊花的“君子之风”，自唐宋以来，赏菊逐渐成为风俗。除了赏菊，人们还会采摘菊花酿酒，至第二年重阳开封饮用。在这个节气前后，人们也会饮用菊花茶，降火消燥。

吃秋蟹

俗话说：“寒露发脚，霜降捉着，西风响，蟹脚痒。”寒露前后，虾蟹繁多。此时母蟹卵满、黄膏丰腴，正是吃母蟹的最佳季节。江南一带有寒露节气蒸螃蟹的习惯。

*登高赏秋*

寒露时节的南方秋意渐浓，天高气爽，阳光和煦，正是出游的好时候。可以漫步自然，看看葳蕤树木变黄的叶片，感受秋天的痕迹；可以登高望远，俯瞰秋天给大地染上的斑斓秋色。
