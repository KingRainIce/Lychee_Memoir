# 如果用星露谷的方式打开深大……

👾🤖👀👒🎈🧡✨🥰   
 如果深大是星露谷   
 我们会在阳光下穿过荔枝林   
 踩着树影去教室   
  
 🚃   
 坐上校巴车   
 仿佛拿到各式各样的图腾   
 随心所欲游览校园   
  
 🍧   
 空气传来香甜的气息   
 那是荔枝临近成熟的季节   
 我们期盼一年一度的   
 “夏威夷宴会”   
  
 ☁️   
 在草坪躺着看云时   
 风会把钢琴声卷成棉花糖   
 有时也会有几声“咕咕”的鸟叫   
 回响在耳畔   
  
 🦆   
 乘着傍晚舒适的风   
 在文山湖边散步之际   
 说不定有粗心鸭鸭掉落高星绒毛   
  
 🐈   
 踏着夕阳回宿舍   
 楼下的小猫对着我伸懒腰   
 尾巴或许会卷成爱你的形状   
  
 🌠   
 从图书馆出来的晚上   
 总能遇见月光给湖面镀上银箔   
 那是游戏随机刷新的隐藏彩蛋   
  
 🌙   
 勤奋的同学们   
 请记住一定要在两点前进入梦乡   
 不要让像素世界的自己超载运转啦   
  
 🍃🍃🍃   
 祝大朋友小朋友们节日快乐   
 在这里生活，我们遇见   
 与像素世界一般鲜活的初夏
