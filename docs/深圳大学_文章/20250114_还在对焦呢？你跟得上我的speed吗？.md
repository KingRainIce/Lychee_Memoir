雀 形目、椋鸟科，无危（LC），国家“三有”保护野生动物。

鸣禽，体长27-30cm。黄色的眼周，像涂了一圈迷人的眼影；黑白斑驳的翼上覆羽，像甜美的巧克力雪糕，还有那系着黑色领环的颈部，优雅十足。除了引人瞩目的外表，我还拥有着电音之嗓，不论你离我多远，我都会和兄弟们为你唱响青春的喜悦！

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zKHPHEmS3iandzlNibbxAIiaWdG3AHia0u7lGFZKibbZdjq2e9JibMlkFGx25Aa2NJ3h6LF6iceQcXMUicI8Q/640?wx_fmt=jpeg#imgIndex=19)

鹈 形目、鹭科，无危（LC），国家“三有”野生保护动物。

涉禽，体长45-50cm。常在水边走，哪能没见过我呢？深褐色的背羽，白色的腹羽，缩着脖子站在岸边，一看就是个厉害的“钓鱼佬”！我的繁殖羽和平常不同，十分亮眼，头、颈和胸深栗色，背黑紫色，喉部及两翼白色。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zKHPHEmS3iandzlNibbxAIiaWdmcBqvqWLRSHicZEt5guiaGnhZH1y7zbbF96wZP31JkWb8nGaDgIgtYhg/640?wx_fmt=jpeg#imgIndex=20)

雀 形目、雀科，无危（LC），国家“三有”野生保护动物。

鸣禽，体长14cm左右。红褐色的头顶，黑色的喉部，像个长有黑胡子的小老头一样。背部暖棕色，带黑色条纹，隐藏在树丛中难以发现。然而，当你发现其中一只，你就很有可能会惊喜地看到一整群麻雀哦！

鸽 形目、鸠鸽科，无危（LC），国家“三有”野生保护动物。

陆禽，体长27-32cm。我们整体色泽较为暗淡，最显著的是颈侧及后部有黑白斑点组成的“项链”，这对我们生存与繁殖大有帮助。我们以筑巢及其敷衍闻名于世，相信你也曾听到过我们低沉而响亮的“谷姑固——顾”吧！

雀 形目、椋鸟科，无危（LC），国家“三有”野生保护动物。

鸣禽，体长25-27cm。作为椋鸟科的一员，哥也拥有无比骄傲的天籁之嗓，喜欢结群作伴。哥的羽毛并不全都是黑色的，当咱飞起来的时候，你可以很清楚地看到翼上有闪亮的白色斑块。而且哥的头部还有一簇立起的羽冠，覆盖鼻孔和嘴基。不愧是哥，长得就是这么英俊霸气！

雀 形目、噪鹛科，无危（LC），国家“三有”野生保护动物。

雀 形目、鹎科，无危（LC）,国家“三有”保护野生动物。

鸣禽，体长18-19cm。俗称“白头翁”，橄榄绿的上体配上白色的下体，像竹叶一样的焦绿色翅膀，是不是把我们认成柳莺啦？其实我们体型要更大一些，最显眼就是那白色的枕羽，像布偶里的棉花不小心从缝隙里钻出来一样，因此得名“白头鹎”啦！

快门速度：

拍摄飞行中的鸟类时，建议使用至少1/1000秒的快门速度。

穿着

鸟类视觉敏锐，容易被惊扰，在着装上要避免颜色鲜艳的衣服，尽量穿着 暗色衣服。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/OJ8hoNiaxSL6TcauqricU1CIsPSDy7dt5Qw8ZEwSDHtdPmfEaJ5q9Gb5azQypmicJ07rMEoEPztQicEOFZjmwibGiayQ/640?wx_fmt=gif#imgIndex=39)

2

声音

观鸟过程中 保持安静， 不要喧哗，不惊吓或追逐鸟类，不过度干扰它们的自然生活状态。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/OJ8hoNiaxSL6TcauqricU1CIsPSDy7dt5Qw8ZEwSDHtdPmfEaJ5q9Gb5azQypmicJ07rMEoEPztQicEOFZjmwibGiayQ/640?wx_fmt=gif#imgIndex=40)

3

灯光

拍摄鸟类采用自然光， 不使用闪光灯， 尤其是对雏鸟，以免惊吓伤害它们，坚决抵制诱拍。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/OJ8hoNiaxSL6TcauqricU1CIsPSDy7dt5Qw8ZEwSDHtdPmfEaJ5q9Gb5azQypmicJ07rMEoEPztQicEOFZjmwibGiayQ/640?wx_fmt=gif#imgIndex=41)

4

距离

遇到鸟类筑巢或育雏时， 保持距离 或尽快离开，以免造成干扰。
