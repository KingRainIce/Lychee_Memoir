HLMEA，基于融合TRE的SLM与LLM协作的无监督实体对齐框架

本文提出了基于混合语言模型的无监督实体对齐方法（Hybrid Language Model-based unsupervised Entity Alignment，HLMEA），将实体对齐（EA）问题转化为一个过滤和单选问题，利用小语言模型（SLMs）与大语言模型（LLMs）的协同，精准地找出存在于不同的知识图谱（KGs）的语义相同实体，从而实现KG融合。
