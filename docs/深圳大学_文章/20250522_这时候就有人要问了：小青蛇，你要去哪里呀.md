文明对话：传统文脉的当代转译

跨越时空的文明对话，汇聚设计学科的深度思考。用艺术复苏敦煌艺术千年瑰宝，用设计唤醒丝路文明的璀璨史诗；《文明的时差》丛书以考古纹样为纽带，解码两大古文明的“无言共鸣”，探索传统纹样的现代转译可能。

全球行动：设计实践的创新突破

红点奖《Play with the Window》用贴纸拼图重构儿童旅行记忆；《世界设计之都可持续发展》系列报告，联合全球学者揭秘设计驱动城市的创新路径，为深圳“设计之都”注入理论动能，师生作品闪耀国际舞台。

智行向前：需求导向的未来提案

依托国家级大学生创新创业项目等产学研平台，推出“未来智行”提案集群。《多功能道路救援车》以模块化设计重塑公共安全，《分体式社区流动医疗急救车》展现设计解决社会痛点的力量。
