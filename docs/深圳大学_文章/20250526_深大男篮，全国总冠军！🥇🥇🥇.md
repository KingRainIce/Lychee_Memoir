5月25日，第27届 中国大学生篮球二级联赛全国总决赛 在山东农业大学举行。 深圳大学男子篮球队 以68:54的比分战胜对手福建师范大学男子篮球队，捧起 全国总冠军 奖杯！

决赛中，深大男篮与福建师大男篮展开了一场惊心动魄的较量。比赛第一节，福建师大率先发力，打出了一波7:2的开局，给深大男篮带来了不小的开场压力，并趁着深大进行场上人员调整的时候，一度建立起不小的领先优势。 在形势危急之时，深大队员伍桓葆以一次漂亮的抢断，快攻得手。 紧接着，深大男篮如猛虎下山，连得5分，成功实现反超。首节战罢，深大以20:18领先。

进入第二节，深大男篮展现出了顽强的团队精神，在防守端紧密协作，筑起了一道坚不可摧的防线，逐渐找回了比赛节奏，让福建师大的进攻屡屡受挫， 通过默契的配合，不断撕开福建师大的防线，稳稳地扩大领先优势。

![](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJ9BgoknovVibaHGuROwU3JR9TRk88dQXOfCNWfx3zqJv3H6sew7xc8jdIOlIfHFicFzLINicE8RKDbQ/640?wx_fmt=jpeg#imgIndex=1)

![](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJ9BgoknovVibaHGuROwU3JRNfQ0RP8x1OXINkCzzhICz8kXLSWqQ0gDVT6u6ANtljj1jEic1wrtWtg/640?wx_fmt=jpeg#imgIndex=2)

第三节，比赛局势风云再变。深大一名主力球员由于累计犯规次数过多下场。这一突发状况对深大男篮的外线进攻造成了巨大影响，进攻火力明显减弱。福建师大趁机发力，抓住机会疯狂追赶比分，比赛进入白热化阶段。

![](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJ9BgoknovVibaHGuROwU3JRkLgyicEibXQGZQ3pfaz0XvN3fySsQwE7LaNjtMwKiaWMrRX0ISJtycOpQ/640?wx_fmt=jpeg#imgIndex=3)

到了决定胜负的第四节， 深大男篮没有丝毫退缩，他们重拾信心，稳扎稳打。 在防守上，他们延续了之前的强硬作风，每一次对手的进攻都面临着重重阻碍；在进攻端，球员们凭借着扎实的基本功和强烈的求胜欲望，不断冲击着福建师大的内线，一次次漂亮的得分，让现场观众为之沸腾。随着比赛时间的流逝，深大男篮凭借着出色的发挥，逐渐将比分拉开，为最终的夺冠奠定了坚实的基础。

![](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJ9BgoknovVibaHGuROwU3JRjdTGoP3axYGVqzP1pqIUSro4S4iaMaIRS1Sdxn2ZqZDEoqXT5LBlbwA/640?wx_fmt=jpeg#imgIndex=4)

最终，深大男篮保持迅猛攻势拿下全场，成功捧起总冠军奖杯。 深圳大学15号李子鸣也拿下总决赛男子MVP（最有价值球员）殊荣。

![](https://mmbiz.qpic.cn/mmbiz_jpg/OaWJibLCM5zJ9BgoknovVibaHGuROwU3JRLELJ8PmDHhmcCNKo1WdtPxRl2OA4j6BcOLFJAWiarPiav2sUdfYSyM6Q/640?wx_fmt=jpeg#imgIndex=5)

全国总决赛阶段，深大男篮以六场比赛全胜、合计胜分131分的战绩捧杯全国总冠军。 颁奖典礼上，队员们高高举起校旗环绕全场，颁奖词也对他们的拼搏精神给予最高褒奖： “他们用汗水浇灌梦想，用团结征服赛场，以无可阻挡的姿态站上巅峰！”
