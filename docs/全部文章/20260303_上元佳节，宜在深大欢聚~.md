# 上元佳节，宜在深大欢聚~

🥰🥰🥰   
 上元佳节，宜“赶集”   
 人间烟火气，最抚人心   
 看这攒动的人头   
 是节日的欢腾   
 是校园里生动的风景   
  
 上元佳节，宜“寻趣”   
 巧手做花灯，慧心解灯谜   
 师生校友与市民同乐   
 把日子过得有滋有味   
  
 上元佳节，宜“食甜”   
 一口软糯入喉   
 甜在舌尖，暖在心头   
 这是我们为你准备的“独家宠爱”   
 愿你这学期，一切皆甜   
  
 上元佳节，宜“相逢”   
 与好友相约   
 与快乐相遇   
 最好的团圆   
 是在这良辰美景里   
 彼此温暖，彼此照亮   
  
 上元佳节，宜“望月”   
 月圆向吉，花开向喜   
 今日灯火可亲   
 愿你眼中有光   
 心中有爱   
 岁岁常欢愉   
 万事皆圆满
