# 左滑充电🔋

你是否也在经历这些：   
 躺在床上刷手机到凌晨   
 明明困意来袭却不舍得睡；   
 看到下学期的选课表   
 心里就会莫名发慌；   
 想到这学期的各种任务   
 突然涌起一阵强烈的焦虑感   
 ……   
  
 别担心   
 这并不意味着你“矫情”或“不够自律”   
 “开学适应期”   
 是一个需要被理解和温柔对待的   
 过渡阶段   
  
 请收下这份   
 帮助你顺利度过“缓冲期”的   
 专属“回血”攻略！   
  
 无论是在日程表里设定小期待   
 还是在新学期中设置小方向   
 都是我们能为自己充电的方式   
  
 元气满满，开启新学期！
