# 😭深大的荔枝今年预计大幅减产

深圳荔枝自3月份进入花期   
 成花量决定荔枝收成   
 今年桂味、糯米糍荔枝树的花穗基本没有   
 只有妃子笑、黑叶等品种情况稍好   
  
 今年导致荔枝树减产的原因有：   
 1️⃣ 2025年冬天气温太高   
 导致新芽大多长成了叶子而非花穗   
 2️⃣去年荔枝产量高   
 过多消耗了树木的养分   
 3️⃣去年冬天以来雨水偏少   
 本应在春节成花的品种果树基本少有花穗   
  
 2025年深大荔枝迎来大丰收   
 不仅有多轮的派发，还有荔枝文化节活动   
 并在食堂上新各种荔枝创意菜   
 今年派发荔枝时可能要靠抢了🤷‍♀️   
 荔枝一般有大小年的规律   
 今年吃不上的话，静静等待明年吧 ![[苦涩]](//res.wx.qq.com/mmbizappmsg/zh_CN/htmledition/js/images/pic/pic_blank7d0395.gif)
