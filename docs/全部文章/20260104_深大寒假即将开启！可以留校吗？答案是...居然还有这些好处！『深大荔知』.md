# 深大寒假即将开启！可以留校吗？答案是...居然还有这些好处！『深大荔知』

![图片](https://mmbiz.qpic.cn/mmbiz_gif/TqDMlFr5tLST6JpoE496x5SVXvx7ZibYF2vYgJf6LOJicjRDsx64FemmD76FSys9Drt1Tv6PZgYAfCSiagovzldRA/640?wx_fmt=gif#imgIndex=0)

深大教务统一安排的期末考试，明天（1月5日）开考啦。 只要考完自己的考试，深大人的寒假就正式开启！

很多人开始考虑寒假的安排， 有人问深大寒假能留校吗？答案是可以的！ 而且好处还不少！

寒暑假期间，深大人免费留校，不需要额外缴纳宿舍费。水费不用交，每天也会有免费热水。 当然，网费、电费则需要自己交（寒暑假，学校不会赠送基础电费）。

寒假会有留校住宿的统计（具体留意下周的班级通知），经过登记之后，宿舍会正常供电。没登记的或许会断电，到时候如果想恢复电源联系宿管开电即可。

至于配套设施，例如 图书馆、体育场馆、食堂 等设施还会开放（具体通知安排本月下旬会发布，可以参考往年通知）。
